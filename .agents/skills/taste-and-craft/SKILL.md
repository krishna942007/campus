# Taste & Craftsmanship Skill — Elite Design Standards

Apply **Taste & Craftsmanship** principles to transform functional code into museum-grade, production software that delights users and stands out from generic AI-generated templates.

---

## 🎨 The 5 Pillars of High-Taste Engineering

1. **Substance Over Emptiness**: Provide meaningful information density (KPIs, badges, timestamps, status indicators) with scannable visual anchors.
2. **Layered Surface Depth**: Replace flat opaque backgrounds with subtle translucent glass, 5px backdrop blur, and 1px micro-rim highlights.
3. **Physics-Driven Motion**: Use organic spring physics (`stiffness: 400, damping: 30`) and `layoutId` transitions.
4. **Optical Precision**: Ensure optical alignment of icons inside pill buttons, tags, and interactive inputs.
5. **No Visual Dead Ends**: Every hover, click, copy, and form submit must provide immediate, delightful visual or haptic feedback.

---

## 🚫 The Anti-Slop Checklist (Review before shipping)
- [ ] No unstyled native HTML elements (select dropdowns, raw buttons, generic scrollbars).
- [ ] No generic pitch-black 20% box shadows; use soft colored depth shadows (`shadow-xl shadow-navy/05`).
- [ ] No layout shifts on loading (always preserve skeleton dimensions).
- [ ] No generic purple/blue gradient button spam without contextual purpose.
- [ ] All display headings above 24px have tight negative tracking (`tracking-tight` / `-0.02em`).
