## Antigravity — Project Intelligence & Token Efficiency Rules

### 1. `BRAIN.md` First & Maintained
- Always maintain [BRAIN.md](file:///c:/Users/HP/Desktop/project1/BRAIN.md) at the root of the project.
- Read `BRAIN.md` before exploring codebase files.
- Update `BRAIN.md` when meaningful architectural or project-level changes occur.

### 2. Token Usage Efficiency
- Treat token usage as a limited resource.
- Avoid unnecessary exploration or scanning the entire repository blindly.
- Inspect only files relevant to the active task (`BRAIN.md` -> relevant files -> implement -> test -> update `BRAIN.md`).

### 3. Clean & Concise Code
- Minimal code, maximum clarity.
- Write the simplest clean implementation that solves the problem.
- Reuse existing project patterns, utilities, and components before introducing new dependencies or abstractions.

### 4. Focused & Intentional Changes
- Make small, targeted changes relevant only to the requested task.
- Avoid unrelated refactoring or reorganization.
- Keep responses concise and focused on what changed and next steps.
